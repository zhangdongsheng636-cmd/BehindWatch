# BehindWatch 1.1.0 · 打工人的后视镜正式就位

工位背对走廊，耳朵不用再兼职雷达了。

**上班摸鱼神器 / 工位背后雷达 / 打工人的电子后视镜**：摄像头留意身后，本地 AI 检测到有人进入你框选的区域时，给一个轻提醒。

## 下载哪个？

- **Windows 用户**：下载 `BehindWatch-1.1.0-Windows-x64.zip`，完整解压，运行 `BehindWatch.exe`。无需安装 Python，保留 `_internal` 文件夹。
- **想改源码**：下载 `BehindWatch-1.1.0-Python-source.zip`，或直接克隆仓库。
- `SHA256SUMS.txt` 提供两个发布附件的文件校验值。

## 这一版有这些

- 摄像头选择、180° 旋转、水平翻转和低分辨率预览。
- 框选检测区、排除自己、灵敏度和停留时间调节。
- 本地 YOLOX-Nano 人体检测、短期跟踪与防重复提醒。
- 角落弹窗 / 任务栏闪烁 / 系统通知 / 提示音 / 边框闪烁。
- 勿扰模式、系统托盘、迷你窗口和折叠状态条。
- 本地事件日志、默认关闭的可选触发截图。
- **数据目录可放 D 盘**，切换时一起复制设置、日志和截图，保留旧数据备份。
- 修复数据库连接释放问题；明确区分“检测画面”和“开始 / 停止监测”。

## 先用这三步

**预览画面 → 框选走廊 / 排除自己 → 开始监测。**

默认不录像、不保存截图，摄像头画面全程本地分析。声音、边框和截图按需要开启。

已通过 17 项自动测试，以及 Windows 11 内置摄像头、打包启动和数据目录迁移验证。Windows 10、更多 USB 摄像头及长时间运行仍需实机覆盖。检测效果受光线、遮挡和区域设置影响，请先在自己工位走一遍测试。

“摸鱼”是昵称，这个小工具只做人体出现提醒，不识别身份，也不保证每次都能检出。
